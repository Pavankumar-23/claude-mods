# model-advisor

Claude Code mod: shows which model (haiku / sonnet / opus) fits each prompt above the prompt box, and can auto-switch to it. Auto-switch is off by default (`autoSwitch` in the plugin config).

## Install

At the prompt of a terminal session or the desktop app:

```
/plugin install model-advisor --marketplace <github-username>/claude-mods
```

From a shell:

```
claude plugin marketplace add <github-username>/claude-mods
claude plugin install model-advisor@pavan-mods
```
